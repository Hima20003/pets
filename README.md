# Good Pet

Static website for Good Pet dog walking in Kingston upon Thames, Surbiton and
New Malden.

## Publish with GitHub Pages

In the repository settings, open **Pages** and set the build and deployment
source to **GitHub Actions**. Push changes to `main` to deploy the site. Once
the deployment succeeds, it will be available at:

https://hima20003.github.io/pets/

The booking form prepares a request in the visitor's email app; it does not
send or store booking details on this site.
